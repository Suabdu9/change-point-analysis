# Change Point Analysis of Brent Oil Prices

## Overview

This project analyzes structural changes in Brent crude oil prices using Bayesian Change Point Detection. The objective is to identify significant shifts in oil prices and associate them with geopolitical events, economic shocks, and OPEC policy decisions.

## Project Objectives

- Explore historical Brent oil prices
- Perform time series analysis
- Detect structural breaks using Bayesian inference
- Associate detected changes with historical events
- Develop an interactive dashboard for stakeholders
